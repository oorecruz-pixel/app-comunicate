Comunicación accesible para todos

¿Cómo quieres comunicarte hoy?

Elige una herramienta para conversar: habla y muestra el texto, escribe para que el teléfono lo diga o usa mensajes rápidos con imágenes.

🎙️ Voz a texto

Pulsa el micrófono y habla. Tus palabras aparecerán aquí para que otra persona pueda leerlas.

Aquí aparecerá el texto reconocido…
Micrófono listo. Puede requerir permiso del navegador.

🔊 Texto a voz

Escribe un mensaje y pulsa “Leer mensaje”. El dispositivo lo dirá en voz alta.

La voz disponible depende de las voces instaladas en el dispositivo y del navegador.

💬 Mensajes rápidos

Toca una tarjeta para mostrar el mensaje y escucharlo en voz alta. Puedes usar estas frases sin escribir.

Selecciona un mensaje para mostrarlo aquí.
